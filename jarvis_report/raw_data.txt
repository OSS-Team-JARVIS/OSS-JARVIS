# JARVIS MCP 기반 자율 제어 에이전트 프로젝트 아키텍처 분석 데이터

## 1. 개요 및 목적
JARVIS 프로젝트는 MCP(Model Context Protocol)를 활용하여 원격 서버 및 로컬 PC의 하드웨어와 소프트웨어를 안전하고 자율적으로 제어하는 지능형 에이전트 시스템입니다. 본 시스템의 주요 목표는 개발자와 운영자가 자연어 프롬프트를 통해 시스템 명령을 수행하고, 자율적인 의사 결정을 거쳐 에이전트가 복잡한 업무를 자동 해결하게끔 돕는 것입니다. 

## 2. 핵심 아키텍처 및 구성 요소
JARVIS는 마이크로서비스 아키텍처(MSA)를 지향하며 다음과 같은 구조로 나뉩니다.
* **Control Hub**: 사용자 입력을 바탕으로 계획을 수립하고 하위 도구를 호출하는 LLM 오케스트레이터입니다.
* **MCP Server**: 데이터베이스, 파일 시스템, 터미널 실행, 웹 브라우징 등의 도구를 API 형식으로 노출하는 어댑터 레이어입니다.
* **Agent Sandbox**: 임의의 코드가 호스트 시스템에 직접 피해를 주는 것을 방지하기 위한 격리된 샌드박스 환경입니다.
* **AI 요약 보고서 모듈 (jarvis_report)**: 웹 검색 및 샌드박스 내부 동작 과정에서 대량으로 쏟아지는 로그와 정보들을 받아 전처리, 청킹, 요약 과정을 거쳐 사람이 한눈에 파악하기 편한 Markdown 보고서를 출력합니다.

## 3. 주요 기능 및 적용 기술
* **Map-Reduce 기반 대량 텍스트 처리**: 제한된 컨텍스트 길이 내에서 원본 텍스트 유실을 최소화하기 위해 입력 데이터를 슬라이딩 윈도우 방식으로 청킹한 뒤 개별 요약(Map)하고 이를 종합적으로 다시 요약(Reduce)하는 설계를 채택했습니다.
* **구조적 무결성 검증기 (Validator)**: LLM이 생성한 결과물이 사전 정의된 보고서 서식(개요, 핵심 내용, 주요 기술, 실행 환경, 기대 효과 등)을 온전히 포함하고 있는지 체크하여 누락 시 재생성을 유도하는 구조입니다.
* **Pandoc 멀티 포맷 퍼블리셔**: 단순 텍스트에 머물지 않고 비즈니스 의사 결정용으로 인쇄 및 배포가 용이하도록 Pandoc을 통해 PDF와 DOCX 등의 문서를 일괄 생성합니다.

## 4. 개발 범위 및 실행 환경
* **언어 및 런타임**: Python 3.11 이상, 가상환경 관리를 위한 `uv` 빌더 사용
* **로컬 LLM 연동**: Ollama 엔진 및 30억 매개변수를 지닌 Qwen2.5:3b 모델을 활용하여 로컬 인프라의 데이터 유출을 막는 오프라인 온프레미스 처리를 기반으로 합니다.
* **호환 시스템**: Windows Server 및 Windows 10/11 환경, VSCode IDE 개발

## 5. 성과 계획 및 기대 효과
JARVIS 에이전트의 자율 운영 결과 및 크롤링 데이터를 문서화함으로써 보고서 작성에 소요되는 리소스를 90% 이상 절감할 것으로 기대됩니다. 로컬 인프라를 활용하여 저비용 고성능 요약을 달성하고 향후 Gemini, Claude 등의 퍼블릭 클라우드 API와의 플러그인식 연동을 통해 모듈의 확장성을 실현할 예정입니다.
